# گذر (Gozar)

پنل مدیریت تونل برای سرورهای شخصی — با رابط وب مدرن، فارسی و راست‌به‌چپ.

## وضعیت فعلی (نسخهٔ ۱.۰.۰)

| بخش | وضعیت |
|---|---|
| پنل مدیریت وب (React) | ✅ آماده |
| سرورها، تونل‌ها، کاربران، تنظیمات | ✅ آماده |
| چند پورت در یک تونل | ✅ آماده |
| محک اتصال بین دو سرور | ⚠️ آماده در پنل — نیازمند ایجنت |
| **ایجنت و انتقال واقعی ترافیک** | ❌ **هنوز ساخته نشده** |

> **مهم:** در این نسخه تونل‌ها ترافیک رد نمی‌کنند. پنل کامل کار می‌کند و
> تونل‌ها ساخته می‌شوند، اما چون ایجنت هنوز وجود ندارد، وضعیت تونل‌ها روی
> «در انتظار» می‌ماند. ایجنت در نسخهٔ بعد اضافه می‌شود.

## نصب پنل

روی سرور (با دسترسی root):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Hosein21378/gozar/main/scripts/install.sh) --panel
```

نشانی پیش‌فرض: `http://IP-سرور:8080`
نام کاربری و رمز پیش‌فرض: `admin` / `admin123`

> **حتماً رمز پیش‌فرض را از بخش «کاربران» عوض کنید.**
> پنل هنگام اجرا اگر رمز هنوز پیش‌فرض باشد، هشدار می‌دهد.

نصب دستی (اگر systemd ندارید):

```bash
./bin/gozar-linux-amd64 serve --addr 0.0.0.0:8080 --data /etc/gozar/data.json
```

## چند پورت در یک تونل

هر تونل می‌تواند هر تعداد پورت داشته باشد:

| نوشته | معنی |
|---|---|
| `443,80,8443` | چند پورت جدا |
| `8000-8010` | بازه |
| `2053=53` | روی ۲۰۵۳ گوش بده، به ۵۳ بفرست |
| `443,80,2053=53,9000-9002` | ترکیب همه |

پورت‌ها روی **سرور ورودی** باز می‌شوند و به **سرور خروجی** می‌روند.
اگر پورتی را که قبلاً به تونل دیگری روی همان سرور داده‌اید دوباره بدهید،
پنل هشدار می‌دهد و سرور آن را رد می‌کند. روی سرورِ دیگر همان پورت آزاد است.

## ترانسپورت‌ها

`خودکار` · `اختصاصی` · `TCPMux` · `TCP` · `WebSocket` · `WSS` · `QUIC` · `KCP`

ترانسپورت **اختصاصی** اختیاری است و هیچ‌وقت خودکار انتخاب نمی‌شود؛
فقط زمانی به کار می‌رود که خودتان آن را برای یک تونل برگزینید.

## ساخت از سورس

پیش‌نیاز: Go 1.24 و Node 20

```bash
cd web && npm install && npm run build
mkdir -p ../server/dist && cp dist/index.html dist/icon.svg dist/manifest.webmanifest dist/sw.js ../server/dist/
cd ../server && go build -o ../gozar .
```

رابط کاربری داخل باینری جاسازی می‌شود (`//go:embed all:dist`)،
بنابراین روی سرور فقط یک فایل اجرایی لازم است.

برای ساخت نسخهٔ نمایش طراحی (داده‌های ساختگی، بدون نیاز به سرور):

```bash
cd web && npm run build:preview   # خروجی: web/preview/index.html
```

## ساختار پروژه

```
gozar/
├── server/          سرور Go و API
│   ├── main.go      نقطه ورود، مسیرها، احراز هویت
│   ├── api.go       endpointهای پنل
│   ├── agent.go     ارتباط با ایجنت‌ها
│   ├── ports.go     قواعد و اعتبارسنجی پورت‌ها
│   └── store.go     ذخیره‌سازی در فایل JSON
├── web/             رابط کاربری React + Vite
│   └── src/
├── scripts/         اسکریپت نصب
└── bin/             باینری‌های آماده
```

## ذخیره‌سازی

همهٔ داده‌ها در یک فایل JSON (`/etc/gozar/data.json`) نوشته می‌شود؛
هیچ پایگاه داده‌ای لازم نیست. کپی گرفتن از همین فایل برای پشتیبان کافی است.
